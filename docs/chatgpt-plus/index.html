先确认：你要购买的是哪一种服务

开通 ChatGPT Plus 只有三条路径：官方网页结算、Apple / Google 应用内订阅、第三方代充。先确认账号、所在地区和可用付款方式，再选路径；付款成功不等于开通成功，最后一步一定要回账号里核对计划状态。

ChatGPT Plus 是个人 ChatGPT 订阅，不是 API 余额，两者计费完全分开：Plus 按月固定扣费，API 按调用量计费，买了 Plus 不会自动获得 API 额度。开通前先确认自己需要的是更高的对话使用额度，还是程序调用能力。

本文负责完整流程；微信支付宝的具体购买要求在第三方充值指南中单独说明。

付款条件和服务可用地区需要分别核对。截至核验日，中国大陆未列入 OpenAI 的 ChatGPT 支持地区；购买第三方服务不会改变官方地区限制。先查看官方支持地区，再决定是否购买。

三条路径各自独立：在哪条路径付的款，之后就要回到同一条路径去查账单、改付款方式和取消续费。最常见的混乱就是网页订过一次、App 又订一次，两边同时扣费。

开通前准备这四项

  1. 确认要升级的账号与登录方式（邮箱、Google、Apple、微软），记录当前计划，避免升级到另一个账号。用 Apple 登录时注意可能是隐藏邮箱，后面找收据要按这个邮箱找。
  2. 查看是否已有网页、Apple 或 Google 的有效订阅，避免跨渠道重复购买。
  3. 核对购买渠道的价格、币种、税费、续费规则及账号信息要求。官方标价通常不含当地税费，结算页金额才是实际扣款。
  4. 确认自己知道在哪里查账单和取消续费，再付款。

官方网页订阅：按页面完成购买

  1. 打开 ChatGPT，登录需要升级的账号。
  2. 从账号菜单进入升级计划，选择 Plus。
  3. 检查结算页的金额与计费周期，填写真实付款信息并完成银行验证。
  4. 付款后查看计划状态和收据；遇到错误先保存报错文字，进入支付排查，不要把反复付款当作验证方法。

结算页会要求账单地址。这里要填发卡机构登记的地址，不是随便找一个——地址与银行记录不一致是被拒的常见原因之一，具体见账单地址怎么填。

使用手机 App 购买时，先确认下载的是 OpenAI 的应用，收据由 Apple 或 Google 提供，后续管理也要回到对应商店。App 内价格可能与网页不同，这是商店渠道费用造成的差异。

第三方充值：先了解交付再下单

第三方商家支持人民币支付，不代表 OpenAI 官网直接支持相同支付方式。交易对象、凭据提交和售后规则均需单独核对。商品名中的“充值”也不意味着时长一定能叠加到现有订阅上——有的商品是给你一个已开通的成品账号，有的是在你自己的账号上操作，两者的账号归属和聊天记录完全不同。

下单前至少问清四件事：交付的是自有账号还是成品号、是否需要提交 Session、失败如何退款、到期后怎么续。如需比较条件，先读中国大陆购买路径对比；已经确定使用第三方，再查看商品页。

付款后用这份清单确认到账

  • 确认当前账号与下单账号一致（看右上角登录邮箱，不看昵称）。
  • 检查计划是否显示 Plus，而不只看某个模型是否出现。模型入口有时是灰度放量，出现与否不能作为开通凭据。
  • 核对扣款收据、交易时间、套餐和下一计费日期。
  • App 内购买未同步时检查恢复购买入口；仍有问题，携带脱敏收据联系实际收款方。
  • 计划未生效时先处理原订单，不另下一单尝试覆盖。

如果扣款成功但账号仍显示 Free，先看开通后检查清单，多数情况是账号搞错或状态未同步，不是钱丢了。

常见追问

ChatGPT Plus 多少钱一个月？
官方标价为每月 20 美元，实际扣款以结算页显示为准，可能另加当地税费。应用商店渠道的价格可能略有不同。第三方人民币报价由商家自行定价，不是官方汇率换算。
开通后多久生效？
官方渠道通常在付款成功、页面确认后即时生效。以账号 Settings 里的计划状态为准；App 内购买偶尔需要手动“恢复购买”同步。
可以用别人的账号帮我开吗？
技术上可行，但账号、聊天记录、上传文件和账单都会绑在那个账号上，后续取消和退款也要通过对方。建议开在自己长期使用的账号上。
买了 Plus 就有 API 额度吗？
没有。ChatGPT 订阅和 API 平台是两套独立计费，API 需要在 platform 侧单独充值。
开通失败会扣钱吗？
银行可能出现预授权占用，通常会在数日内自行释放，是否真正入账需要向银行确认。不要因为看到扣款短信就反复重新下单。
