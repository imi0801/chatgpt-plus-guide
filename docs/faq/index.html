没有海外卡，先核对哪些条件？

先核对官方支持地区、可用付款方式与第三方交付要求。第三方支持人民币付款，不代表官方地区限制已解除。详细步骤见无海外卡路径选择。

支付被拒是不是账号有问题？

通常不是。更常见的原因是银行卡、虚拟卡、账单地址、地区和风控问题。不要短时间反复提交。

建议使用共享账号吗？

不建议。共享账号存在聊天记录混乱、密码被改、权限被收回、数据不属于自己的问题。长期使用最好把订阅开在自己的账号上。

开通后怎么确认成功？

  1. 刷新 ChatGPT 页面。
  2. 进入头像或订阅管理页面。
  3. 查看当前计划状态。
  4. 检查模型和工具权限是否变化。
